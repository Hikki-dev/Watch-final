# Changes

What changed in each version, newest first.

## 1.1.0 (24 October 2026)

The app is written up as a guided tour, as the shopper half of a pair with Laravel-Watch.

* **New:** a README tour of every screen, a "two repos, one store" section and a diagram
* **New:** guides for getting started, how it fits, how it works, fixing problems and questions
* **New:** an MIT licence, contributing and security pages, issue forms and a pull request form
* **New:** a social preview picture
* **Better:** the README now says plainly that checkout in the app is a placeholder and that the web demo is offline

## 1.0.0 (22 October 2026)

A new look.

* **New:** a light and dark theme, with a switch that is remembered
* **New:** bundled fonts, brand logo plates and a 360 viewer for watches with frames
* **New:** free web hosting set up with GitHub Pages
* **Fixed:** Google sign in now sends the Firebase token to the store, which checks it

## 0.2.0 (January 2026)

Accounts and polish.

* **New:** change your name and your profile picture
* **New:** brands that follow the catalogue, with fallback icons
* **New:** images load through the API so the web version works
* **Fixed:** clearer sign in errors

## 0.1.0 (November 2025)

The first working app: Firebase sign in, the catalogue, favourites, a cart, and seller and admin screens, talking to the Laravel store.
